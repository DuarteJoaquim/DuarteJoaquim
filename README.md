## 📂 Highlighted Projects

Here are some of the key projects I have built, showcasing a wide range of architectures and design patterns:

### Distributed & Web Systems
* **[DAD Memory Game Platform](https://github.com/DuarteJoaquim/DAD-Memory-Game-Platform):** A distributed real-time multiplayer memory game. Built with **Vue 3, Laravel 10 APIs, and Socket.io WebSockets** with full container configurations for **Docker** and **Kubernetes**.
* **[DAE Academic Publications Platform](https://github.com/DuarteJoaquim/DAE-Academic-Publications-Platform):** An enterprise-level repository for scientific papers. Features a **Jakarta EE** WildFly backend, a **Nuxt 3** frontend, and local LLM writing assistants via **Ollama/TinyLlama**.

### AI & Logistics Integrations
* **[FARUP Logistics Platform](https://github.com/DuarteJoaquim/FARUP-Logistics-Platform):** An e-commerce backend platform. Combines a **Python catalog scraper**, a **Spring Boot backoffice**, carrier integrations (**DHL & CTT Expresso APIs**), and **Google Gemini AI** to optimize package sizes.

### Mobile & Desktop Applications
* **[TAES Mobile Wallet App](https://github.com/DuarteJoaquim/TAES-Mobile-Wallet-App):** A cross-platform digital banking mobile app built using **React Native, Expo, and Firebase** for authentication, contacts management, and real-time ledger transfers.
* **[LifeStats Desktop App](https://github.com/DuarteJoaquim/LifeStats-Desktop-App):** A clean desktop dashboard client for managing personal routines, habits, task lists, and finances, compiled with **Electron**.
* **[MATHura Senior Math Game](https://github.com/DuarteJoaquim/MATHura-Senior-Math-Game):** A serious mathematical educational game developed in **Unity (C#)** designed around senior citizen accessibility guidelines.
